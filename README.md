# Coratech Global (CG)

**Innovating Your Digital Future** • Agile Technology Powerhouse delivering scalable software development, managed IT support, cloud infrastructure, Google Business Profile optimization, and certified hardware solutions.

---

## 🚀 Features

- **Dynamic Public Website**: Ultra-responsive dark/light cybernetic UI with particle circuit canvas, interactive service scope modals, dynamic multi-currency converter, interactive cost estimator, and client ticket tracking.
- **Dedicated Admin CMS Portal (`/admin`)**:
  - **Laptops & Store**: Add, edit, delete, and upload photos for developer and business laptops.
  - **Portfolio & Case Studies**: Publish case studies with metrics and tech stack tags.
  - **Support Helpdesk**: Live ticket triage and SLA diagnostic step tracking.
  - **Appointments & Inquiries**: Consultation booking schedule and newsletter management.
  - **Global Settings**: Currency exchange rates and WhatsApp number configuration.
- **Full-Stack REST API & Persistence**: Node.js & Express server with JSON datastore and multer image upload handling.

---

## 🛠 Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 Glassmorphism, Font Awesome 6
- **Backend Server**: Node.js, Express.js
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs
- **Media Storage**: Multer disk storage (`/uploads/`)
- **Database**: Persistent JSON datastore (`data/database.json`)

---

## 🏁 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm start
```
- Public Website: [http://localhost:3000](http://localhost:3000)
- Admin CMS Portal: [http://localhost:3000/admin](http://localhost:3000/admin)
  - Default Login: `admin@coratechglobal.com`
  - Default Password: `admin1234`
